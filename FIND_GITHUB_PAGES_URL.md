# Finding Your GitHub Pages URL

## Quick Way to Find It

1. **Open your repository on GitHub.com**
   - From GitHub Desktop: Click **View on GitHub** (top right)
   - Or go to: `https://github.com/YOUR_USERNAME/YOUR_REPO_NAME`

2. **Go to Settings → Pages**
   - Click **Settings** tab (top right of repository)
   - Scroll down and click **Pages** (left sidebar)

3. **Your URL is shown at the top**
   - It will say: "Your site is live at `https://YOUR_USERNAME.github.io/REPO_NAME/`"

## URL Format

GitHub Pages URLs follow this format:
```
https://YOUR_USERNAME.github.io/REPO_NAME/
```

**Examples:**
- If your username is `nick123` and repo is `crm-rev-2`:
  - URL: `https://nick123.github.io/crm-rev-2/`
- If your username is `johndoe` and repo is `CRM-Rev-2`:
  - URL: `https://johndoe.github.io/CRM-Rev-2/`

## Find Your Username

1. Go to https://github.com/
2. Click your profile picture (top right)
3. Your username is in the URL or shown at the top

## Find Your Repository Name

1. Open GitHub Desktop
2. Look at the top center - it shows your repository name
3. Or check the folder name you created

## If Pages Isn't Enabled Yet

1. Go to your repository on GitHub.com
2. Click **Settings** → **Pages**
3. Under **Source**, select:
   - Branch: `main` (or `master`)
   - Folder: `/ (root)`
4. Click **Save**
5. Wait 1-2 minutes, then refresh the Pages settings
6. Your URL will appear at the top

---

**Your URL will be: `https://YOUR_USERNAME.github.io/REPO_NAME/`**
