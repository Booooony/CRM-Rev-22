Import from Excel

How to Import:

  1. Open your Excel spreadsheet
  2. Select and copy the data (including headers): Equipment Type, Category, Model Number, Description, Lead Time, Cost, Drawing Number
  3. Paste the data into the text area below
  4. Click "Import Data" to add items to the catalogue
  5. You can upload images for each item later using the upload button in the table
